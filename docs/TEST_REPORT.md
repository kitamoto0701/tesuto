# 初期版の検証結果

検証日：2026-10-31。Python 3.12 / Django 5.2.18 / Linux。

## 実行済み
- `python manage.py test`：17件中16件成功、PostgreSQL専用同時登録テスト1件はSQLite環境のためスキップ。
- 全11台帳の一覧・登録フォーム・CSV、ダッシュボード、ユーザー管理、操作履歴、パスワード画面のHTTP応答確認。
- ログイン必須、ロール外アクセス403、工事担当への契約金額非表示・改変防止。
- 最大10有効ユーザー、11人目拒否、上限時の再有効化拒否、自分自身の無効化拒否。
- 無効化済みユーザーの既存セッション拒否、管理者のパスワード再設定後の既存セッション失効。
- CSRFなしPOST拒否、GETログアウト拒否、ログイン失敗5回で制限。
- 日付逆転、進捗101%、不存在案件、負額、過入金の拒否。
- Decimalによる数量×単価計算、バージョン競合409、操作履歴作成、CSV数式対策、HTMLエスケープ。
- `makemigrations --check --dry-run`：変更なし。
- 本番相当設定で `check --deploy`：警告なし。DB接続先はダミーで、これは設定検査のみ。
- 実際にDjango HTTPサーバーを起動し、Cookie/CSRFを伴うログイン→架空案件登録→ダッシュボード→ログアウトを成功確認。healthでDB到達性確認。
